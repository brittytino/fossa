---
title: Creating a Webhook
description: "Manually create the GitLab webhook when automatic registration didn't happen, and select the events Fossa consumes."
icon: webhook
---

Fossa usually creates the webhook automatically. If that didn't happen, follow these steps to set it up manually:

<Note>
  Webhook URLs must reach the Webhooks service (port 3332). Using the API domain only works if your reverse proxy routes `/.../webhook` paths to the webhooks service.
</Note>

1. Navigate to your GitLab project
2. Go to "Settings" > "Webhooks"
3. Configure your webhook:

   - **URL**: Enter the URL from your `.env` file: `API_GITLAB_CODE_MANAGEMENT_WEBHOOK`
   - **Check Show full URL**
   - **Name**: (optional) Fossa Code Review
   - **Description**: (optional) Fossa Code Review Webhook
   - **Secret token**: Leave blank
   - **SSL verification**: Enable SSL verification
   - **Trigger**: Select the following events:
     - Comments
     - Merge request events

4. Click "Add webhook"

You've successfully set up a webhook for code reviews in your GitLab repository.

<Note>
  Fossa consumes comment and merge request events only. Issue events are discarded on arrival.
</Note>
