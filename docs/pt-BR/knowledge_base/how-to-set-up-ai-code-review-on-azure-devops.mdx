title: "Como configurar revisão de código com IA no Azure DevOps"
description: "Instale e configure o Fossa para repositórios Azure DevOps e receba revisão de código automatizada com IA em cada pull request."
---

O Fossa integra-se com o Azure DevOps via webhooks. Uma vez configurado, cada pull request é revisado automaticamente.

## Passos

1. **Crie uma conta** em [fossa.local](https://github.com/brittytino/fossa) ou [hospede o Fossa por conta própria](/pt-BR/how_to_deploy/deploy_fossa/generic_vm)
2. **Conecte o Azure DevOps** — autorize durante a configuração e configure seu Personal Access Token
3. **Configure os webhooks** — siga a configuração guiada para habilitar eventos de pull request
4. **Selecione os repositórios** — escolha quais repositórios Azure DevOps o Fossa deve revisar
5. **Abra um pull request** — o Fossa o revisa automaticamente

## O que você recebe

- Revisões automatizadas em cada PR
- Comentários postados diretamente no pull request
- Regras personalizáveis e controles de sugestões
- Validação de lógica de negócio contra itens de trabalho vinculados

## Configuração personalizada

Coloque um `fossa-config.yml` na raiz do seu repositório para personalizar o comportamento por repositório. O arquivo substitui as configurações da interface automaticamente.

## Usando um Personal Access Token

O Azure DevOps requer um PAT para que o Fossa acesse seus repositórios e poste comentários de revisão. Certifique-se de que o token tem os escopos adequados para leitura de código e acesso a comentários de PR.

Para o guia completo de configuração, consulte [Azure DevOps Webhooks](/pt-BR/how_to_deploy/platforms/azure_devops/azdevops_webhook) e [Azure DevOps PAT](/pt-BR/how_to_use/code_review/general_config/azure_devops_pat).
