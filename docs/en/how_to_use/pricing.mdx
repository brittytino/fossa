## True BYOK (Bring Your Own Key)

FOSSA does **not** sell LLM tokens or charge markups. FOSSA is pure open-source software that communicates directly with your chosen AI provider using your own credentials:

| What you pay FOSSA | What you pay your AI Provider |
| :--- | :--- |
| **$0.00 (Free forever)** | You pay your provider directly at their standard API rates (Anthropic, OpenAI, Google Gemini, OpenRouter, or $0 for local models via Ollama/vLLM) |

- **No Markups:** FOSSA never adds margins or hidden fees on top of model API calls.
- **Data Sovereignty:** Your code and prompts travel directly between your self-hosted instance and your chosen model provider. No 3rd-party SaaS intercepts your source code.
- **Model Flexibility:** Switch between frontier models (Claude 3.7 Sonnet, GPT-4o) and cost-efficient models (Gemini 2.5 Flash, DeepSeek R1) per repository at any time.

See the [BYOK Setup Guide](/en/how_to_use/byok) for step-by-step instructions on connecting providers.

## Self-Hosting Quickstart

Run the complete platform locally or on your own server in minutes:

```bash
# Clone the repository
git clone https://github.com/brittytino/fossa.git
cd fossa

# Copy environment config
cp .env.example .env

# Start with Docker Compose
pnpm run docker:start
```

Once running, the web dashboard is accessible at `http://localhost:3000` with all features unlocked.
