---
title: "Cómo configurar la revisión de código con IA en GitHub"
description: "Instala y configura Fossa para repositorios de GitHub para obtener revisión de código automatizada con IA en cada pull request."
---

Configurar Fossa en GitHub lleva solo unos minutos. Una vez conectado, cada pull request se revisa automáticamente.

## Pasos

1. **Crea una cuenta** en [fossa.local](https://github.com/brittytino/fossa) o [aloja Fossa tú mismo](/es/how_to_deploy/deploy_fossa/generic_vm)
2. **Conecta GitHub** — instala la aplicación de GitHub de Fossa cuando se te indique durante la configuración
3. **Selecciona repositorios** — elige qué repositorios debe revisar Fossa
4. **Abre un PR** — Fossa lo revisa automáticamente y publica comentarios

## Qué obtienes

- Revisiones automatizadas en cada PR (o bajo demanda con `@fossy start-review`)
- Comentarios publicados directamente en el PR con sugerencias de código
- Reglas, filtros de severidad y límites de sugerencias personalizables
- Validación de lógica de negocio contra tareas vinculadas

## Configuración personalizada

Coloca un archivo `fossa-config.yml` en la raíz de tu repositorio para personalizar el comportamiento por repositorio. El archivo anula la configuración de la web automáticamente.

## Usar un Token de Acceso Personal

Para repositorios privados u organizaciones con permisos más estrictos, es posible que necesites configurar un Token de Acceso Personal (PAT) de GitHub.

Para la guía de configuración completa, consulta [Inicio Rápido](/es/how_to_use/quickstart) y [Configuración de la aplicación de GitHub](/es/how_to_deploy/platforms/github/github_app).
