description: "Instale e configure o Fossa para projetos GitLab e receba revisão de código automatizada com IA em cada merge request."
---

O Fossa integra-se com o GitLab via OAuth e webhooks. Uma vez configurado, os merge requests são revisados automaticamente.

## Passos

1. **Crie uma conta** em [fossa.local](https://github.com/brittytino/fossa) ou [hospede o Fossa por conta própria](/pt-BR/how_to_deploy/deploy_fossa/generic_vm)
2. **Conecte o GitLab** — autorize via OAuth durante a configuração
3. **Configure os webhooks** — siga a configuração guiada para habilitar eventos de merge request
4. **Selecione os projetos** — escolha quais projetos GitLab o Fossa deve revisar
5. **Abra um merge request** — o Fossa o revisa automaticamente

## O que você recebe

- Revisões automatizadas em cada MR
- Comentários postados diretamente no merge request
- Regras personalizáveis e controles de sugestões
- Validação de lógica de negócio contra tarefas vinculadas

## Configuração personalizada

Coloque um `fossa-config.yml` na raiz do seu repositório para personalizar o comportamento por projeto.

Para o guia completo de configuração, consulte [GitLab OAuth](/pt-BR/how_to_deploy/platforms/gitlab/gitlab_oauth) e [GitLab Webhooks](/pt-BR/how_to_deploy/platforms/gitlab/gitlab_webhook).
