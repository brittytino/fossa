GitHubにFossaをセットアップするには数分かかります。接続されると、すべてのプルリクエストが自動的にレビューされます。

## 手順

1. [fossa.local](https://github.com/brittytino/fossa)で**アカウントを作成**するか、[Fossaをセルフホスト](/ja/how_to_deploy/deploy_fossa/generic_vm)します
2. **GitHubに接続** — セットアップ中にプロンプトが表示されたらFossa GitHub Appをインストールします
3. **リポジトリを選択** — Fossaがレビューすべきリポジトリを選択します
4. **PRをオープン** — Fossaが自動的にレビューしてコメントを投稿します

## 得られるもの

- すべてのPRでの自動レビュー（またはオンデマンドで `@fossy start-review`）
- コード提案付きでPR内に直接投稿されるコメント
- カスタマイズ可能なルール、重要度フィルター、提案数制限
- リンクされたタスクに対するビジネスロジック検証

## カスタム設定

リポジトリごとの動作をカスタマイズするには、リポジトリルートに `fossa-config.yml` を配置します。ファイルはウェブ設定を自動的にオーバーライドします。

## 個人アクセストークンの使用

プライベートリポジトリやより厳格な権限を持つ組織では、GitHub個人アクセストークン（PAT）を設定する必要がある場合があります。

完全なセットアップガイドについては、[クイックスタート](/ja/how_to_use/quickstart)と[GitHub Appセットアップ](/ja/how_to_deploy/platforms/github/github_app)を参照してください。
