    <Tab title="Claude (Anthropic)">

        ```env
        # Claude Configuration
        API_LLM_PROVIDER_MODEL="claude-3-5-sonnet-20241022"
        API_ANTHROPIC_API_KEY="sk-ant-api03-..."
        ```
    </Tab>

    <Tab title="OpenAI">
        Native integration using `@ai-sdk/openai` with structured outputs and reasoning effort support.

        ```env
        # OpenAI Configuration
        API_LLM_PROVIDER_MODEL="gpt-4o"
        API_OPEN_AI_API_KEY="sk-proj-..."
        ```
    </Tab>

    <Tab title="Google Gemini">
        Native integration using `@ai-sdk/google` (Google AI Studio) or `@ai-sdk/google-vertex`.

        ```env
        # Google Gemini Configuration
        API_LLM_PROVIDER_MODEL="gemini-2.5-flash"
        API_GOOGLE_AI_API_KEY="AIzaSy..." # or GEMINI_API_KEY="AIzaSy..."
        ```
    </Tab>

    <Tab title="OpenRouter">
        Route any model through OpenRouter (Claude, DeepSeek, Llama, Gemini, etc.).

        ```env
        # OpenRouter Configuration (endpoint auto-configured to https://openrouter.ai/api/v1)
        API_LLM_PROVIDER_MODEL="anthropic/claude-3.5-sonnet"
        API_OPEN_ROUTER_API_KEY="sk-or-v1-..."
        ```
    </Tab>

    <Tab title="OpenAI-Compatible (Groq, Together, Ollama, vLLM)">
        Point Fossa at any custom OpenAI-compatible provider or local inference engine.

        ```env
        # Custom Provider / Local Proxy Configuration
        API_LLM_PROVIDER_MODEL="llama-3.3-70b-versatile"
        API_OPENAI_FORCE_BASE_URL="https://api.groq.com/openai/v1"
        API_OPEN_AI_API_KEY="gsk_..."
        ```
    </Tab>

    <Tab title="Automatic Fallback API (Resilience)">
        Ensure 100% review uptime: if your primary model encounters rate limits (HTTP 429) or upstream outages (HTTP 5xx), Fossa automatically fails over to the fallback model.

        ```env
        # Primary Model
        API_LLM_PROVIDER_MODEL="claude-3-5-sonnet-20241022"
        API_ANTHROPIC_API_KEY="sk-ant-api03-..."

        # Automatic Fallback Model
        API_LLM_FALLBACK_PROVIDER_MODEL="gemini-2.5-flash"
        GEMINI_API_KEY="AIzaSy..."

        # Optional: dedicated fallback key or base URL (if not using global provider keys)
        # API_LLM_FALLBACK_API_KEY="your-fallback-key"
        # API_LLM_FALLBACK_BASE_URL="https://openrouter.ai/api/v1"
        ```
    </Tab>
